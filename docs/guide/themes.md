# Themes & layout

Open the **Appearance** section at the top of the editor.

| Setting | Options |
| --- | --- |
| **Font** | Ubuntu, Lato, Open Sans, Roboto, Source Sans 3, Merriweather, Georgia |
| **Template size** | Small (7pt base), Medium (8pt), Large (9pt). Headings scale proportionally. |
| **Line spacing** | Compact, Normal, Relaxed |
| **Section spacing** | Compact, Normal, Relaxed |
| **Accent colour** | Any colour via the picker or hex field, or one of the presets |

!!! tip "Fitting on one page"
    If your resume spills onto a second page, try **Small** template size with **Compact** section spacing before cutting content.

!!! info "Fonts"
    Web fonts other than Georgia are loaded from Google Fonts. Your resume data is never sent anywhere. See [Privacy](../privacy.md).
