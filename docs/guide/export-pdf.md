# Exporting to PDF

1. Click **Download PDF** in the toolbar.
2. In the print dialog:
    - **Destination:** *Save as PDF*
    - **Headers and footers:** **off**
    - **Margins:** **None** (padding is built into the template)
3. Save.

Browsers usually remember these settings for next time.

## Troubleshooting

??? question "There's a date, URL or page title on my PDF"
    Turn off **Headers and footers** in the print dialog (under *More settings* in Chrome).

??? question "Colours are missing"
    The template forces colours to print, but some browsers still need **Background graphics** enabled in the print dialog.

??? question "It spills onto two pages"
    Try a smaller template size or compact spacing. See [Themes & layout](themes.md).

??? question "Safari / Firefox look slightly different"
    Chromium-based browsers (Chrome, Edge, Brave) give the most consistent output.
