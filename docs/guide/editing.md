# Editing your resume

The screen is split in two: the **editor** on the left and a live **A4 preview** on the right. Changes appear in the preview immediately and are saved automatically.

## Sections

| Section | What to put there |
| --- | --- |
| **Personal info** | Name, headline/title, a short summary, email, phone, LinkedIn, GitHub and an optional profile photo. |
| **Work experience** | One entry per role: title, company, dates, location, bullet points and an optional tech stack line. |
| **Skills** | A list of skills shown as tags. |
| **Community** | Open-source projects and blog posts, each with an optional link. |
| **Education** | Degree, institution, start and end year. |
| **Achievements** | Awards, certifications, notable results. |

## Tips for strong bullet points

- Start with a verb: *Led*, *Built*, *Reduced*, *Shipped*.
- Quantify: *"Cut p95 latency by 40%"* beats *"Improved performance"*.
- Keep each bullet to one or two lines in the preview.

## Starting over

**Reset template** in the toolbar restores the sample content. This overwrites what is saved in your browser, so export first if you want to keep a copy.
