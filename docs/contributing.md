# Contributing

Contributions are welcome, from typo fixes to new templates.

- Read the full guide in **[CONTRIBUTING.md](https://github.com/parvez3019/novo-style-resume-builder/blob/main/CONTRIBUTING.md)**.
- Pick up a [`good first issue`](https://github.com/parvez3019/novo-style-resume-builder/labels/good%20first%20issue).
- Ask questions in [Discussions](https://github.com/parvez3019/novo-style-resume-builder/discussions).

## Local setup

```bash
npm install && npm run dev          # app
pip install -r requirements-docs.txt
mkdocs serve                        # these docs
```

Before opening a PR, run `npm run lint`, `npm run build` and `mkdocs build --strict`.

New to the codebase? Start with [Architecture](architecture.md).
