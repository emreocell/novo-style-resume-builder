# FAQ

??? question "Is it really free?"
    Yes. It's MIT-licensed open source, with no paywall, watermark or premium tier.

??? question "Do I need an account?"
    No. Open [the app](https://parvez3019.github.io/novo-style-resume-builder/) and start typing.

??? question "Where is my data stored?"
    Only in your browser's `localStorage`. See [Privacy](privacy.md).

??? question "Can I use it on another computer?"
    Data doesn't sync. Export **ATS Text** on one device and [import](guide/import.md) it on the other.

??? question "Is this the official Novo Resume?"
    No. It's an independent educational project and isn't affiliated with Novo Resume / NovoResume. "Novo-style" refers to a common two-column layout.

??? question "Will my resume pass an ATS?"
    The PDF has selectable text, and the **ATS Text** export is plain text designed for parsers. Content still matters most. See [ATS resume tips](ats-tips.md).

??? question "Can I add my own template?"
    Yes, PRs are welcome. See [Architecture](architecture.md) and [Contributing](contributing.md).
